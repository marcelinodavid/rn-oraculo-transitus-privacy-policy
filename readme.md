# Política de Privacidad de Oráculo Transitus

Última actualización: Mayo de 2026

Oráculo Transitus es una aplicación diseñada para ofrecer frases puente y reflexiones que pueden ayudar al usuario a observar sus estados emocionales desde una perspectiva diferente.

## Información que recopilamos

Oráculo Transitus no solicita registro de usuarios y no recopila información personal como nombre, dirección de correo electrónico, número telefónico o ubicación.

## Uso de la aplicación

Todo el contenido de Oráculo Transitus se encuentra integrado dentro de la aplicación. El uso de la aplicación no requiere crear cuentas ni proporcionar datos personales.

## Almacenamiento de información

Oráculo Transitus no almacena información personal en servidores propios ni comparte información personal con terceros.

## Servicios de terceros

Actualmente la aplicación no utiliza servicios publicitarios ni herramientas de análisis destinadas a recopilar información personal de los usuarios.

En caso de que futuras versiones incorporen servicios adicionales, esta Política de Privacidad será actualizada para reflejar dichos cambios.

## Seguridad

Aunque la aplicación no recopila información personal, se procura mantener buenas prácticas de seguridad para ofrecer una experiencia confiable a los usuarios.

## Menores de edad

El contenido de Oráculo Transitus está orientado principalmente a adolescentes y adultos. Se recomienda para usuarios mayores de 13 años.

## Cambios a esta política

Esta Política de Privacidad podrá actualizarse ocasionalmente. Cualquier cambio será publicado en la versión más reciente de este documento.
